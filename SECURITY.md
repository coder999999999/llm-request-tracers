# Security

This repo is a static site (HTML, images, one video). It has no server, no build step and no dependencies.

If you find something that shouldn't be public here, such as a leaked credential or personal data, please report it privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/coder999999999/llm-request-tracers/security) rather than opening a public issue.
